カタリスト・スペースと NASA、スウィフト天文台軌道上昇計画を中止

米宇宙企業カタリスト・スペース（Katalyst Space Technologies）と米航空宇宙局（NASA）は8月20日、同社が開発した Link 宇宙機を用いて NASA の γ線観測衛星 Swift の軌道を上昇させるミッションを中止すると発表した。同機の姿勢制御に生じた複数の問題が安全な軌道上昇作業を実現できないと判断したためである。

Swift は2004年に打ち上げられた主力の γ線バースト観測衛星であり、20年以上にわたって重要な天文学的観測を続けてきた。現在、高度343～347キロメートルの軌道を周回している。ところが太陽活動の異例の活発化により、予想を上回る大気ドラッグが衛星に作用し、軌道の減衰が加速した。このままでは2026年末までの大気圏再突入は避けられないという状況に直面していた。NASA はこの事態に対応するため、昨年カタリストと Cambrian Works（Astroscale U.S. と提携）に軌道上昇の実行可能性を検討する研究契約を発注した。本年9月には、カタリストに3000万ドルの本格契約を授与し、実際のミッション実施を委ねることにした。このプロジェクトは単なる衛星救済ではなく、カタリスト自身の衛星軌道上昇・整備技術の初期実証という側面を強く持つ、高リスク・高リターンの挑戦だった。

Link は7月3日にペガサス XL ロケットで打ち上げられた直後から技術的な課題に見舞われた。7月28日には、3基の反作用ホイールのうち2基が機能を失い、軌道制御用スラスタも部分的にしか動作していない状態で、最大9度/秒に及ぶ多軸スピンに陥ったことが判明した。カタリスト・チームは軌道変更用の電動スラスタを活用してこのスピンを1.47度/秒にまで鎮静化させ、さらに8月11日には新しいソフトウェアをロードして対応を進めていた。当時の発表では、更新されたシステムが Swift への接近・捕捉を支援し、軌道上昇の実施へと進むとの見通しが示されていた。しかし、その後の検討を経て、両者は Link が Swift に安全に接近して捕捉し、確実に軌道を上昇させることができないと判断し、ミッション中止を決定するに至った。なお、接近操作自体は実施される予定である。

衛星軌道上昇・整備は、今後の宇宙開発戦略の中核をなす技術分野だと考えられている。老朽化した衛星の寿命延長は低投資で大きな価値を引き出す手段であり、軌道上でのデブリ除去や機器のメンテナンスは、今後の宇宙の持続可能な利用環境を左右する極めて重要な領域である。今回のミッション中止は、こうした先端的で複雑な軌道作業の実現がいかに技術的に困難であるかを示す象徴的な事例となった。しかし同時に、カタリスト CEO は「今回得た知見を今後の衛星整備ミッションに組み込む」と述べており、失敗からの学習価値は大きい。実際、カタリスト社は先ごろ米国防イノベーション部隊（DIU）および宇宙開発庁（SDA）から衛星デオービット・サービスの研究契約を新たに獲得している。

日本の精密部品メーカー、制御システムメーカー、素材・材料サプライヤーにとって、衛星軌道上昇・整備技術の発展は直接的な需要拡大をもたらす可能性がある。軌道環境における信頼性が求められる反作用ホイール、スラスタなどの軌道制御機器、過酷な条件下での長期稼働を前提とした電子部品や材料は、こうした先端的で高難度なミッションの成否を大きく左右する基盤技術である。本ミッションの中止は個別には残念な結果だが、今後の衛星軌道上昇・整備産業の成長を見据えれば、こうした試行錯誤を通じた技術蓄積が必ずや将来のプロジェクトに活かされることになる。
